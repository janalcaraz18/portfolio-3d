# Portfolio 3D — sitio profesional

Web estática de portfolio diseñada siguiendo el enfoque de funnel del Module 06:
1. **Hero:** nombre, especialidad, visual principal y CTA para ver el trabajo.
2. **Showreel + proyectos:** reel destacado y cuatro tarjetas de proyectos.
3. **About + skills:** presentación breve, software y áreas de trabajo.
4. **Proyectos y créditos:** espacio para proyectos académicos, personales y publicaciones verificables.
5. **Journal:** sección opcional para breakdowns y artículos de proceso.
6. **Contacto:** enlace de email visible en la navegación y al final de la página, más perfiles sociales.

## Personalizar antes de compartir
- Reemplaza `Nombre Apellido`, `NOMBRE·3D`, las iniciales `NA` y el email `tu.email@ejemplo.com`.
- Sustituye los bloques de ejemplo por tus propios renders. No publiques créditos o testimonios que no sean reales.
- Cambia los enlaces genéricos de ArtStation, LinkedIn y Vimeo por tus perfiles reales.
- Para mostrar el showreel, sube `showreel.mp4` junto a `index.html` y descomenta el elemento `<video>` dentro del bloque del reel.
- Añade solo herramientas y habilidades que puedas defender en una entrevista.
- Si quieres ofrecer el CV, sube un archivo llamado `CV.pdf` y añade el enlace correspondiente.

## Publicar con GitHub Pages
En el repositorio, ve a **Settings → Pages → Deploy from a branch**, selecciona `main` y `/(root)`, y guarda. La URL esperada es https://janalcaraz18.github.io/portfolio-3d/.

La página usa HTML, CSS y JavaScript nativos; no requiere dependencias ni compilación.
