# Portfolio 3D — versión personalizada

Diseño minimalista, claro y editorial. Idioma: español. Perfil: Generalista 3D.

## Personalización
- Abre `index.html` y sustituye `Nombre Apellido`, `NOMBRE·3D` y `tu.email@ejemplo.com`.
- Sustituye los bloques «Añade aquí...» por imágenes de tus renders.
- Coloca tu CV en PDF en la raíz del repositorio con el nombre `CV.pdf`.
- Cambia los enlaces de ArtStation y LinkedIn por tus perfiles reales.

Para insertar un render, reemplaza el contenido de un bloque `.project-image` por:
```html
<img src="imagenes/mi-render.jpg" alt="Descripción del render" style="width:100%;height:100%;object-fit:cover">
```

Es una web estática y adaptable a móvil. Puedes publicarla con GitHub Pages.
